Java 安裝紀錄

發布日期：2022-02-24 · 分類：安裝筆記

安裝 JDK

  1. 前往 Oracle 官網 下載 jdk-20 版本（官方每 3 年提供一版長期支援版本）。
  2. 將檔案下載並安裝至 C:\Program Files\Java\jdk-20。
  3. 新增安裝路徑至系統環境變數 JAVA_HOME。
  4. 將路徑正式收錄進系統變數 Path，參數設定為 %JAVA_HOME%\bin。
  5. 完成設定後，即可在系統中編譯並執行 Java 環境（註：上一次安裝紀錄約在 2023 年 1 至 2 月左右）。

何為 JDK？

注意事項：JDK 並不是 Java 語言本身，它其實是一個包含開發工具與執行環境的大集合，主要由以下三個大元件組成：

  1. Java 程式語言
  2. 工具程式：如 javac、javadoc 等。
  3. JRE：內部包含了 Java SE API 與 JVM。

編譯與執行流程（CMD）

  1. Edit（編輯）：撰寫 Java 原始碼。
  2. Compile（編譯）：使用 Java 語言編譯器 javac，透過指令 javac <className>.java 將 .java 檔編譯成 <className>.class。
  3. Load（載入）：JRE 裡面的 JVM 調用 java（指令 java <className>），將 .class 檔放入記憶體中。
  4. Bytecode Verification（位元組碼驗證）：確認該 .class 檔遵守規範，且不會損壞電腦上的文件或系統。
  5. Execute（執行）：將 bytecodes 轉換成機器語言並正式執行。

IDE 開發環境

開發工具使用 VS Code，只要在擴充功能商店下載 Java 的延伸模組即可開始撰寫程式碼。

HelloWorld 範例

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("HelloWorld");
    }
}

注意：Java 檔案名稱必須與 public class 的名稱完全相同，且一個檔案中 public class 只能有一個。
